### AR過程
#### AR(1)過程
AR過程の一番単純なモデル.
\\[
	Y_t = \phi_1 Y_{t-1} + W_t \\\\
	\mathrm{E}[W_t] = 0 \\\\
	\mathrm{V}[W_t] = \sigma^2 \\\\ 
	\mathrm{Cov}[W_t,W_{t-s}] = 0 \\\\
\\]
について考察する.
\\[
\begin{align}
	Y\_t &= \phi_1 Y_{t-1} + W_t \\\\
	&= \phi_1(\phi_1 Y_{t-2} + W_{t-1}) + W_t \\\\
	&= {\phi_1}^2 Y_{t-2} + \phi_1  W_{t-1} + W_t \\\\
	&= {\phi_1}^2 (\phi_1 Y_{t-3} + W_{t-2}) + \phi_1  W_{t-1} + W_t \\\\
	&= {\phi_1}^3 Y_{t-3} + {\phi_1}^2 W\_{t-2} + \phi_1  W_{t-1} + W_t \\\\
	&= {\phi_1}^t Y_{0} + \sum^{t}\_{s=1} {\phi_1}^{t-s} W\_{s}
\end{align}
\\]
なので,\\(|\phi_1| < 1\\)の時は,過去遡るほどその影響は小さくなり,
\\(\phi_1 = 1\\)の場合は,同じように影響し,
\\(|\phi_1| > 1\\)の場合は,過去遡るほど現在に影響する.
