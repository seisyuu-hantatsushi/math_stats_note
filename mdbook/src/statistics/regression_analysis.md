# 回帰解析
とある観測値\\(y\\)と関連する複数の観測値\\(x_i,i=1,2,...,k\\)が組として得られているとする.
\\(y\\)が\\(x_i,i=1,2,...,k\\)から得られる値として,以下の様な式,モデルを考える.
\\[
	y = \beta_{0} + \beta_{1}x_1 + \beta_{2}x_2 + \cdots + \beta_{k}x_k
\\]
\\(\beta_i\\)の真の値はわからないが,観測値を多数集めれば,\\(\beta_i\\)の値を推定できて,\\(x_i,i=1,2,...,k\\)から\\(y\\)を推定する根拠が得られる.
この様な手法を回帰解析という.
